# IDEA React

## Submission for the IDEA Front-End Assessment Task

### Description

For this task, I utilized a free API endpoint to simulate network calls. The following tools and technologies were implemented to enhance the application:

- **React Query**: To manage caching and improve performance.
- **Redux**: For global state management, enabling features such as adding and removing items from favorites using Redux Toolkit slices.
- **Tailwind CSS/Schadcn**: A CSS and UI library to enhance the visual appeal of the application.
- **Custom Hooks**: To abstract complex or bulky logic for better code organization.
- **TypeScript**: To provide a better development experience through type safety.

Additionally, I included a folder named `refactoring_task` (for Question #3 in the task document) containing two files:

- `refactor_init.jsx`: The initial file provided in the task.
- `refactored.jsx`: The refactored version of the code.

### Setup Instructions

To set up the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/JosephVoid/idea-react-assessment
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Rename .env.example to .env.
4. Start the development server:
   `npm run dev`

This setup will enable you to run the application locally and explore its features.
